# 轮式载具接触运动模块

通过**显式形状查询**（射线 / 球体扫描）逐轮确定轮地支撑，由悬挂弹簧阻尼与
轮胎接触力驱动刚体底盘，而不是按键直接改车体位置。本文档先给出图形入口，
再说明物理链路、诊断字段、可重放输入与无头命令行辅助工具。

## 1. 图形入口（主要使用方式）

启动本地服务：

```bash
cd vehicle_contact
python3 -m cli.vc serve            # 默认 http://127.0.0.1:8000/
# 或指定端口
python3 -m cli.vc serve --port 8123
```

浏览器打开服务地址即进入**接触演练视窗**。页面完全离线，不依赖任何 CDN。
以下命令仅作辅助，主要使用方式是浏览器中的视窗。

### 视窗能做什么

- **可驾驶车辆**：`W/↑` 油门、`S/↓/空格` 制动、`A D / ← →` 转向；
  鼠标拖拽旋转视角，滚轮缩放。
- **实时改悬架参数**：时间常数 τ、最大行程、弹簧刚度 k、轮胎摩擦 μ、
  形状查询方式（球体扫描 / 射线），改动立即作用于下一步物理。
- **结果区呈现轮地接触与车身运动**：
  - 车身位置 / 速度 / 速率 / 姿态角 / 接触轮数 / 车身是否触地；
  - 每轮接地状态、行程百分比、压缩量、法向载荷、滑移率、轮速、
    **接地滚动转角**与**悬空自由转角**（分开累计）、所用查询类型；
  - 接触法线（红色箭头）、接触点（白色横杠）、悬挂支柱、车速矢量。
- **异常分组提示**：右侧“接触界面异常提示”分为**轮地接触**与**车身运动**
  两组，分别列出车轮失去 / 重新获得支撑、悬挂打底、全部车轮悬空，以及
  车身壳体触地等异常。
- **录制 / 回放**：`record inputs` 录制当前驾驶输入并导出 JSON 回放文件；
  `回放标准输入` 加载 `data/replays/` 下的确定性场景回放。
- **与 Python 引擎校验**：`与 Python 引擎校验` 把本地 JS 引擎轨迹发回
  `/api/verify`，与参考 Python 引擎在相同输入下逐步比对，结果显示
  `MATCH` 或 `DIVERGENCE` 及最大位置误差、接触数误差。

## 2. 轮地模块边界（重构后）

支撑查询、悬挂计算与轮胎作用已拆到 `engine/wheel_ground/`（JS 对应
`web/js/wheel_ground.js`），接触坐标系接口统一：

- `frames`：接触点相对速度与接触力都以法向 / 纵向 / 侧向的接触坐标分量
  交换，车体侧只做一次 `omega × r` 力臂展开。
- `support`：显式射线 / 球体扫描只回答“地形在哪里、法线朝哪”，**命中只是
  候选支撑**；仍由有限悬挂可达距离 `rest_length + max_travel` 判定是否真正
  支撑。超出可达距离的命中不产生任何力，也绝不沿用旧表面作为无限支撑。
- `suspension`：压缩状态与弹簧 / 阻尼力评估。
- `tire`：纵向滑移、摩擦圆限制、侧向抓地与轮速积分。
- `module`：逐轮编排并发布物理结果（含求解时的轮心、锚点与支撑方向）。

**可见轮子只消费物理结果**：视窗绘制使用模块发布的轮心 `w.center`，不在
渲染时重新查询或重新推导悬挂几何。

**兼容适配**：旧入口 `engine.vehicle.Vehicle` 保留原有公开接口，内部委托给
轮地模块；`LegacyVehicleAdapter`（`vehicle.legacy_adapter()`）为仍按逐轮
方法调用的载具接触代码提供 `queried_contact` / `wheel_force` / `wheel_spin`
等兼容适配。载具接触调用方无需改接即继续运行。

**冻结的外部行为与等价性**：`data/evidence/` 保存重构前的原始逐字段记录
（`slope_raw.csv`、`edge_raw.csv`、`reference_manifest.json`，含 SHA-256）。
重构后的引擎必须逐字段精确复现这些记录；`tests/test_wheel_ground.py` 覆盖：

- 斜面 `slope`：全程四轮支撑——作为**截面支撑**前后差分；
- 边缘 `edge`：单侧车轮离地（4→3→2 接触）——作为**轮子离地**前后差分；
- 由轮地作用（支撑 / 力 / 行程 / 轮速）与车体轨迹共同限定等价性；
- 命中超出可达距离不构成支撑、旧表面不保留。

## 3. 接触如何产生运动（物理链路）

每个固定步长（`dt = 1/120 s`）对每个车轮执行：

1. **形状查询确定支撑**：从车体上的悬挂锚点沿悬挂方向（车体下方）发射
   射线或球体扫描，命中返回接触点、法线、距离。未命中或超出
   `rest_length + max_travel` 即判为悬空，该轮不产生任何力。
2. **悬挂压缩**：`compression = clamp(rest_length - hit_distance, 0,
   max_travel)`。弹簧力 `k·compression` 与阻尼力 `c·compression_vel`
   沿接触法线作用于真实接触点。阻尼系数由时间常数 τ 映射到阻尼比 ζ，
   面板实时显示 ζ。
3. **轮胎纵向力**：驱动力矩先改变轮速，接触斑由滑移率
   `κ = (Rω − v_long)/max(|v_long|,|Rω|,1)` 经摩擦圆 `μ·load` 限制产生
   纵向力；侧向力在剩余摩擦预算内消除侧向接触速度。
4. **刚体积分**：所有悬挂力与轮胎力按接触点相对质心的力臂累加为合力 /
   合力矩，更新线速度、角速度、位置与姿态（四元数）。
5. **车轮滚动累计（两路分开）**：
   - 接地轮 `spin_ground` 按真实滚动关系 `ω_roll = v_long/R` 累计；
   - 悬空轮 `spin_air` 只在残余驱动 / 制动力矩下自由积分。

   可视转角为两者之和，因此悬空转轮不会与车体运动矛盾。

### 边缘不沿用旧地面

球体扫描具有有限半径：车轮中心一旦越过平台侧边缘，查询只命中更低的
地面，且落差大于悬挂总行程，该轮立即判悬空（接触点置空、力为零），
不会把旧的平台顶面继续当作支撑。射线查询在坡道上则会如实报告后轴尚未
接触坡面。

## 3. 三个验收场景

| 场景 | 地形 | 预期现象 |
|------|------|----------|
| `slope` | 12° 上坡 + 下坡连续山丘 | 全程 4 轮接触，无打底、无车身触地 |
| `bump`  | 多个余弦起伏鼓包 | 全程 4 轮接触，悬挂行程随起伏变化 |
| `edge`  | 坡道上台 + 侧向硬边缘平台 | 转向后单侧车轮越边，接触数 4→3→2，回正后恢复 |

### 无头运行与轨迹记录（命令行仅作辅助）

```bash
# 运行场景，打印车体运动 / 接触数量 / 行程 / 异常，并导出 CSV 轨迹
python3 -m cli.vc run slope --csv data/replays/slope.csv
python3 -m cli.vc run bump  --csv data/replays/bump.csv
python3 -m cli.vc run edge  --csv data/replays/edge.csv

# 生成标准确定性回放（JSON）与 CSV
python3 -m cli.vc record

# 回放某个输入文件，可临时覆盖悬架参数观察差异
python3 -m cli.vc replay data/replays/edge.json --tau 0.30 --travel 0.30

# 运行引擎测试套件
python3 -m cli.vc test
```

CSV 列包含时间、车体 XYZ 位置 / 速度、速率、接触数、车身触地标志、
四轮压缩量、首轮接地 / 悬空转角，可直接用于绘制真实轨迹与数值曲线。

## 4. 双引擎一致性

- Python 引擎位于 `engine/`，无头测试与参考轨迹以它为准。
- JavaScript 引擎位于 `web/js/`，图形界面本地运行同一物理。
- `tests/js_parity.js` 用 Node 回放标准输入并与 Python CSV 逐步比对：
  缓坡 / 起伏达到机器精度（~1e-10），边缘场景因跨运行时浮点顺序经硬悬架
  放大，位置误差在厘米级且**接触数零误差**。
- 浏览器内的 `/api/verify` 提供同样的在线交叉校验。

## 5. 目录结构

```
vehicle_contact/
├── engine/
│   ├── wheel_ground/  # 轮地模块边界：frames / support / suspension / tire / module
│   │                  #   以及 interface（物理结果）与 legacy（旧入口兼容适配）
│   ├── vehicle.py     # 旧入口 Vehicle：底盘积分 + 兼容外观，委托轮地模块
│   └── ...            # 数学、地形查询、模拟、场景
├── cli/               # vc.py 无头命令行；server.py 图形界面托管 + 校验 API
├── web/               # 零依赖图形接触演练视窗（Canvas 3D + JS 轮地模块）
├── tests/             # Python 单元/集成测试与 JS 一致性脚本
├── data/replays/      # 标准回放 JSON 与轨迹 CSV
├── data/evidence/     # 重构前原始记录（逐字段 CSV + SHA-256 清单）
└── docs/              # 本文档
```
